# `android/`

Everything needed to produce the Android app, and nothing that the build
produces.

| File | In git | What it is |
|---|---|---|
| `twa-manifest.json` | yes | The whole build, as data. Bubblewrap reads it. |
| `release.keystore` | **no** | The signing key. Lose it and you cannot update a sideloaded install. |
| `android.keystore.jks`, `*.apk`, `*.aab`, `app/`, `build/`, `gradle*` | no | Generated by `bubblewrap build`. |

`bubblewrap` is deliberately **not** a dependency of this repo. It is a
one-command-a-month tool with a large dependency tree of its own, and pinning
it here would mean carrying it in every `npm install` that has nothing to do
with Android. `npm run android:build` invokes it through `npx`.

See `../docs/ANDROID.md` for the procedure, and `../src/lib/android.ts` for the
three values that must agree between this file, `/.well-known/assetlinks.json`
and the Play Console.
